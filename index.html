の作り方・使い方・運用レジュメ

GeminiのカスタムGem機能とNotebookLMを組み合わせ、企業情報から「選考対策＆企業魅力完全ガイド（HTML）」を1発で自動生成するためのチーム共有用完全マニュアル。

1. ワークフロー 2. Gem設定手順 3. 入力フォーマット 4. NotebookLM連携 5. クオリティ向上Tips

1. 仕組みと全体ワークフロー

企業情報や対策テキストを入力するだけで、候補者へそのまま共有・印刷（PDF化）可能なデザイン済みの単一Webページ（HTML）を出力します。

STEP 01 📚

情報収集・整理

求人票、企業HP、選考フィードバックメモなどをNotebookLMにアップロード。

STEP 02 ⚡

データ抽出一括変換

抽出用プロンプトを使い、フォーマットに沿ったテキストを一瞬で生成。

STEP 03 🤖

Gemへのデータ投入

作成したGemini（カスタムGem）のトーク画面に抽出テキストをそのまま送信。

STEP 04 🌐

HTML / PDF出力

1つの完成されたHTMLコードが出力。保存してブラウザ表示・PDF保存が可能。

指示 (Instructions) 最適化されたシステムプロンプト（下記の枠内）をそのまま全文章コピー＆ペーストして貼り付けます。

ユーザーから提供される【提供データ】をもとに、候補者向けの「選考対策＆企業魅力完全ガイド」となる高品質な単一HTMLファイル（Single File HTML）コードを出力してください。

### 【絶対遵守事項】
・解説メッセージや前置きは最小限にし、すぐにコピペして使える ```html から始まるコードブロックを出力してください。
・データに記載されているテキスト（質問内容、NG軸、BETTER軸、模範回答、条件面など）は、要約や省略をせずすべて網羅して盛り込んでください。

### 【作成・デザイン要件】
1. **形式:**
   - 外部ファイル（CSS/JS）を分けず、完全な1つの .html ファイルとして出力。
   - スタイリングには CDN経由の Tailwind CSS (<script src="https://cdn.tailwindcss.com"></script>) を使用。
   - Google Fonts ("Noto Sans JP") を読み込み、洗練されたフォント・余白・影（box-shadow）を適用。

2. **構成・レイアウト:**
   - **ヒーローヘッダー:** 企業カラーを基調としたグラフィック背景、企業名、タイトル、概要、スムーズスクロール対応のナビゲーションタグ。
   - **SECTION 1: 企業魅力・強み（インフォグラフィック）:**
     - 強みや実績数値をカードデザインで強調。
     - 選考・アサインのプロセス等は、Tailwind CSSによるステップ型のフロー図（ダイアグラム）として視覚化。
   - **SECTION 2: 面接前確認事項（理念・カルチャー・条件面）:**
     - 理念・バリュー（行動指針など）を綺麗に整理。
     - 候補者が使える「具体例を交えた模範回答（★回答例★）」を表示。
     - 条件面（転勤・勤務地など）の質問・標準回答・実態背景をカード等で整理。
   - **SECTION 3: 想定質問・必須問い対策:**
     - 原文のニュアンス、面接官の意図、NG回答例、BETTER回答例を一切省略せず掲載。
     - 各質問ごとに「NGな軸（赤系）」「BETTERな軸（緑系）」「重要注意点（オレンジ系）」「具体的な模範回答例（青・緑系）」を装飾ブロックで色分け。
   - **SECTION 4: 参考URL集:**
     - 参考URLを、タップしやすいカード型のリンク一覧として設置（`target="_blank"` を付与）。

3. **レスポンシブ＆印刷対応:**
   - スマホ・PC完全対応。
   - `@media print` 設定を入れ、印刷時にはナビゲーションや不要な装飾が非表示になり、A4で綺麗に印刷できるデザインに調整。

5. クオリティを劇的に引き上げる 4つの Tips

TIP 01

カラーイメージの具現化

単に「青」と指定するより、「ダークネイビー（#0A192F）とスカイブルー」のようにベース色とアクセント色を補足指定すると、グラデーションやカードのデザイン性が大幅に向上します。

TIP 02

「★回答例★」は口語体で入れる

回答例はデザイン上ハイライト表示されるため、「〜と考え、〇〇を実行しました」という実際の面接で発話するセリフ形式で入力しておくと候補者にとって実用的になります。

TIP 03

コードが途中で止まった場合

長文HTMLのため生成が途中で止まることがあります。その際は慌てず「コードの続きを ```html から出力してください」と指示を出すと正確に結合できます。

TIP 04

保存とPDF化テクニック

出力コードを 選考対策.html で保存しブラウザで開く。Ctrl + P（Macは Cmd + P）を押すと、組み込まれた印刷スタイルによりヘッダー類が消えて綺麗なA4 PDFが作れます。
